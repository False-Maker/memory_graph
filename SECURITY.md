# Security Policy

## Supported Scope

This repository ships a Web application stack based on:

- React Web frontend
- FastAPI backend
- Nest sidecar

## Reporting a Vulnerability

Do not open a public issue for an undisclosed vulnerability.

Use a private reporting channel configured by the repository maintainer on the hosting platform. If no private security channel is configured yet, contact the maintainer privately before publication.

## What to Include

Please include:

- affected component and file path
- reproduction steps
- impact assessment
- proof-of-concept only when necessary
- any suggested fix or mitigation

## Secret Handling

Never include real credentials in reports. Use redacted examples for:

- API keys
- passwords
- internal hostnames
- deployment env files
